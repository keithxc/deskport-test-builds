# DeskPort full-content canvas self-test

Connection progress, takeover confirmation and remote video now replace the entire window content area. DeskPort navigation returns with the Devices page. Windowed mode retains system window controls; fullscreen hides them. macOS switches its unified Devices title bar on the existing native window.

The final macOS, Windows and Linux consumers each passed 16 native decoded presentation stages. Live mouse connections confirmed the full-content canvas across all three clients; fullscreen and windowed restore were observed on each client, with Windows Devices recall retaining the same window handle. Physical mouse-border resize was not successfully revalidated in this revision. An interval with a manual resolution change is excluded from uninterrupted streaming acceptance.

macOS assets are Developer ID signed, notarized and stapled; the extracted ZIP and Nix consumer passed Gatekeeper. Both Nix system configurations were built. macOS and Linux activation remains manual. These checks do not accept audio, HDR, latency or long-duration behavior.
