DeskPort 2.0.0 PC self-test for macOS arm64 and NixOS x86_64. This build adopts the portable desktop core while preserving existing display, stream, and keyboard behavior.

The macOS ZIP is Developer ID signed, notarized and stapled. It passed Gatekeeper checks after ZIP extraction. Linux builds natively from the immutable source archive with the recorded version override. Windows packages will be added after their installer audit.
